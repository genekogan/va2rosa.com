# va2rosa.com

The personal site of Vanessa Rosa, Brazilian visual artist and art historian.
Built with [Astro](https://astro.build), static output, no client framework.

Live at **[vanessarosa.art](https://vanessarosa.art)**.

## Running it

```bash
npm install
npm run dev     # http://localhost:4321
npm run build   # writes dist/
```

## How it is put together

Content lives in plain JavaScript modules under `src/data/`, not in a CMS.
Adding a project usually means adding an object to a data file rather than
writing a page.

| Path | What is in it |
| --- | --- |
| `src/data/` | All the text: the curriculum, press, shows, threads, films, the shelf |
| `src/pages/` | One file per route; most just hand a data object to a layout |
| `src/components/` | `WorkPage` (the project layout), the timeline, the world map, the book reader, the cursor field |
| `src/styles/global.css` | One stylesheet for the whole site |
| `public/` | Images, video, fonts, and the `_redirects` / `_headers` the host reads |
| `scripts/` | Helpers: gallery generation, rendering a book PDF to page images |

A few things worth knowing:

- **`src/data/domain.js`** holds the canonical URL. Canonical tags, the sitemap,
  `robots.txt` and the machine-readable files all read from it.
- **`public/_redirects`** maps every page of the old cargo.site to its
  replacement here, so old links keep working.
- **`src/data/galleries.js`** is generated by `scripts/build-galleries.mjs` from
  what is actually in `public/images/`, so a missing file cannot silently break
  a page.
- **`/for-ai`, `/llms.txt`, `/for-ai.json`** are written for machines. There is
  no visible link to them.

## Deploying

Static output; any host will do. Config for three of them is committed, so
switching is a matter of pointing DNS somewhere else:

| Host | Reads | Notes |
| --- | --- | --- |
| Cloudflare Pages | `public/_redirects`, `public/_headers` | Unlimited bandwidth on the free plan |
| Netlify | `public/_redirects`, `public/_headers`, `netlify.toml` | A drag-and-drop deploy ignores `netlify.toml` |
| Vercel | `vercel.json` | Ignores `_redirects` and `_headers` entirely |

Build command `npm run build`, output directory `dist`, on all three.

`vercel.json` is generated from `public/_redirects` — if you add a redirect,
add it there and regenerate, so the two cannot drift apart.
